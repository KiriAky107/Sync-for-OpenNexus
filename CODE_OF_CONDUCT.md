# Code of Conduct

OpenNexus contributors must communicate respectfully, critique work rather than people, protect private information, credit others accurately, and follow project security and licensing rules.

Harassment, discrimination, threats, spam, denial-of-service behavior, impersonation, fabricated attribution, plagiarism, or publication of credentials, private logs, Vault data, infrastructure details, or another person's identity is not acceptable.

This policy applies to Issues, Pull Requests, reviews, releases, deployment discussions, and other spaces representing Sync for OpenNexus. Maintainers may remove content, lock discussions, reject contributions, or restrict participation when necessary.

Use GitHub reporting controls for ordinary moderation concerns. Vulnerabilities or reports containing sensitive evidence must follow [SECURITY.md](SECURITY.md) and must not be posted publicly.
